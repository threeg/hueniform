Hueniform · Visual Design

A wardrobe that knows its colours

The full interface for Hueniform — a local-first wardrobe colour-matching app. Six screens, every state, in the warm “Soft Paper” system. The chrome stays quietly neutral so the only true colour on screen belongs to your garments.
